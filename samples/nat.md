# 自然数算术教学文献

MATHLIB2_DEMO_NAT

本文件为项目自编的教学样例，不是已发表论文。定义域均为自然数，包含真命题、错误猜想与未解决候选。

## Lemma 1 加零不变
对任意自然数 n，n + 0 = n。
证明：自然数加法定义。

## Theorem 2 两次加零
对任意自然数 n，(n + 0) + 0 = n。
证明：应用引理 1 两次。DAG 依赖：Lemma 1 → Theorem 2。

## Proposition 3 错误猜想
对任意自然数 n，n + 1 = n。
反例：n = 0。

## Proposition 4 有限搜索的边界
对任意自然数 n，n * n = n。
该命题为假（n = 2），但本演示反例角色仅尝试 n = 0，因此允许返回 unknown。

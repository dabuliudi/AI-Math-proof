## 明确限制

1. 环境变量不是密码保险箱；同权限进程或管理员可能读取进程环境。脚本避免明文命令历史和磁盘Key文件，但不能保证Python字符串等内存被完全擦除。
2. 脱敏针对已配置密钥及常见模式，不是任意编码/任意个人信息的完整DLP。不要把其他凭证或敏感资料放入数学目标，且只向自己信任的服务地址发送Key。
3. 日志是本地文件和哈希链，不是不可变签名存储。目录访问权限继承项目配置；未擅自修改ACL。供应商request_id/model字段仅是响应元信息。
4. HTTP请求失败或超时可能已产生费用；unknown不能记0。本地预占基于显式价格和Token上限，无法约束服务商隐藏开销、错误价格、不同分词和账户其他进程的支出。
5. 所有失败响应在可获取范围内保存；超过256KiB的部分明确标未保存。进程被外部强制终止时可能只留下事前request记录，须视为结果/费用未知。
6. 不同兼容服务、模型、公司网络/代理环境尚需实测；首版不通过自动降级协议、关闭TLS或改用备用模型来掩盖失败。
